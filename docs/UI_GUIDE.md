# UI 指南

## 视觉方向

使用白色主背景、深蓝绿色品牌色、深灰正文和少量橙色提醒。界面强调可信、安静、清楚，避免渐变炫技、玻璃拟态和装饰性 AI 元素。

## Design tokens

共享 token 位于 `packages/shared-ui/tokens.css`。基础间距为 8px；圆角 8–12px；阴影只用于浮层和重点容器。

## 机构端

固定侧栏 + 顶栏 + 最大内容宽度。列表优先使用表格，筛选与操作贴近任务。原文审核固定为左右对照，风险字段同时用图标、文字和颜色表达。

## 用户端

375px 移动优先，正文默认 18px、1.8 行高，最小点击区域 48px。详情首屏优先展示标题、来源与“三句话看懂”，底部操作保留“听、大字、收藏、原文”。支持 18/20/22/24px 和高对比度。

## 可访问性

使用语义标签、可见焦点、按钮文本、状态文字和 `aria-label`；不单独依赖颜色；动画遵守 `prefers-reduced-motion`。

## 统一中文词表

- 产品名称统一使用“简达助手”。
- 字号与阅读模式入口统一使用“大字阅读”。
- 从通俗版进入权威原始材料的入口、页面标题统一使用“查看原文”；下载操作使用“下载原文”。
