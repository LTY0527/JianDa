# Phase 9.7 H5 体验报告

## 收口结果

- 原首页的“今天要紧的事 / 重要提醒 / 大场通知 / 长辈常用 / 最近更新 / 按分类查看”合并为单一推荐入口。
- 首屏为强搜索、8 个可恢复频道、单 Hero、5 个高频服务和连续 Feed。
- Hero 只放大真实已审核封面；无真图时使用文字 Hero，不放大分类 SVG。
- Feed 实际支持图文、风险提醒、活动日期、服务、机构目录和纯文字条目，不使用成排大圆角卡片。
- 频道切换复用已加载数据，Playwright 断言首页 API 请求始终为 1。
- 配色使用品牌绿、政务蓝、健康青、活动橙和风险红，同时保持暖灰背景和高对比文字。

## Before / After 差异台账

| 维度 | Before | After |
| --- | --- | --- |
| 信息入口 | 多个纵向大模块 | 8 频道 + 1 条连续 Feed |
| 主视觉 | 多卡片竞争 | 单一真实官方 Hero |
| 快捷任务 | 散落在不同模块 | 5 个高频服务集中呈现 |
| 内容节奏 | 重复白卡 | 图文/风险/服务/活动/文字混排 |
| 响应式 | 组件级局部适配 | 375/390/768/1440 与 18/20/22/24px 自动断言无横向溢出 |

桌面端仍显示消费端底部导航，这是保留的跨视口一级导航，不是本轮新增导航。
