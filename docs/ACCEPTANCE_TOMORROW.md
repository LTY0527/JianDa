# 明日教师验收手册

## 启动与地址

```powershell
docker compose build
docker compose up -d
docker compose ps
```

- 机构端：`http://127.0.0.1:8090`
- 用户端：`http://127.0.0.1`
- 后端健康：`http://127.0.0.1:8080/actuator/health`
- AI 健康：`http://127.0.0.1:8001/health`

演示账号使用 README 中的本地演示账号；密码由验收人员在本机配置或现场提供，
不要写入截图、报告或提交记录。

手机局域网地址可用 `ipconfig` 查看电脑当前 IPv4，然后访问
`http://电脑IPv4`。手机与电脑需连接同一可信局域网。

## 推荐演示顺序

1. 平台管理员登录，打开独立“运营看板”(`/operations`)，说明来源、采集、AI 预算、
   图片/内容待审、平均耗时和错误均来自数据库而非演示常量。
2. 进入权威来源，依次演示“发现文章”“影子采集”“立即采集”：前两步不创建材料、
   不调用 AI，立即采集只进入 `WAITING_APPROVAL`；强调调度、自动 AI、审核和发布默认关闭。
3. 上传一份官方 PDF，展示真实原文件、提取文本、字段引用和人工审核。
4. 预览并导入一篇白名单网页文章；展示 canonical URL、正文快照和版本信息。
5. 查看懒加载、srcset、OpenGraph/JSON-LD 等来源形成的图片候选；说明禁止缓存不会删除
   机构端候选，只有人工确认来源和使用依据后才可公开，未确认时使用分类默认图。
6. 在机构端人工确认、审核并发布选定测试内容，不批量自动发布。
7. 打开用户端首页，核对权威来源、真实封面/分类图、发布时间和响应式布局。
8. 进入详情，核对字段、来源、原文、电话/地址操作和上一篇/下一篇。
9. 在 iPhone Safari 手动点击“听全文”，验证分段进度、暂停、继续、停止和离页停止。
10. 打开简达助手，分别核对“平台运行状态”“原文检索”“已审核内容 + AI 整理”和
    “通用 AI 参考”；检查最多三条引用，并确认医疗诊断、资格、金额、材料等无依据问题拒答。
11. 返回机构端刷新运营数据，核对浏览与助手提问计数增长。

## iPhone Safari 清单

- [ ] 390px 首页、资讯、办事、助手和详情无横向滚动。
- [ ] 24px 大字模式下标题、图片、正文和底部操作栏不重叠。
- [ ] 朗读只能由点击启动，优先中文声音。
- [ ] 长文分段播放并显示“第 n / m 段”。
- [ ] 暂停后继续会从当前段重新开始，没有多个声音叠加。
- [ ] 快速重复点击、切换文章、返回首页或关闭页面会停止旧队列。
- [ ] 不支持语音时显示大字阅读降级提示。
- [ ] 左右滑动不抢占按钮、链接和文本选择。

## 常见恢复

```powershell
docker compose ps
docker compose logs --tail 120 ai-service backend frontend
docker compose up -d
```

不要执行 `docker compose down -v`。模型失败时保留现场，助手应自动降级为检索；
内容处理失败时保留原文件、任务和日志，禁止用静态结果伪装成功。
