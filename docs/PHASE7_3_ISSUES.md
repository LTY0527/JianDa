## 分级标准

- **P0 阻断**：服务、登录、上传处理审核发布主流程不可用；权限泄露；数据丢失；白屏或崩溃。
- **P1 严重**：导航、引用过滤、安全返回、持久化、375px 布局、原文入口或固定操作区影响核心使用。
- **P2 一般**：对齐、间距、颜色、文案、加载反馈和非核心响应式问题。
- **P3 建议**：动画、非必要入口和未来功能建议。
