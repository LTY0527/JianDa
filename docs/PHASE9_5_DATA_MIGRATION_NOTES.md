# Phase 9.5 数据迁移说明

## V23：内容生命周期

为发布内容增加生效、截止、过期、最近核验、来源更新时间和核验状态。现有数据允许为空，旧内容不会因迁移自动过期或被删除。

## V24：提醒与使用事件

新增匿名游客提醒和最小使用事件表。事件只保存业务事件类型、内容关联和匿名会话，不引入浏览器指纹、广告 ID 或精确位置。

## V25：居民账号与邻里

新增居民账号、会话、帖子、点赞、评论和举报表。密码保存 BCrypt，居民会话只保存 SHA-256 token 摘要。种子账号与帖子均标记 DEMO。

## 实际迁移结果

Docker 使用既有 MySQL volume 启动，Flyway 成功校验 25 个 migration，并从 V21 顺序应用 V22、V23、V24、V25，最终 schema 为 V25。未执行 `down -v`，未重建或清空业务数据库。

回滚策略为恢复应用旧版本并根据备份人工处理新增表/列；不要通过修改已提交 migration 或直接删除 volume 回滚。
