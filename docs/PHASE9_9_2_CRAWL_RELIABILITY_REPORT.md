# Phase 9.9.2 采集可靠性报告

- 批量加入改为 `POST .../collect-batch` 立即返回 202 和 jobId，后台执行并通过 job API 恢复进度。
- UI 记录本轮 job 所有权，刷新后从 localStorage 恢复；展示成功、重复、失败与当前条目。
- 顶层运行异常写入明确失败终态，不再留下无期限 RUNNING。
- 候选增加相关度、分数、推荐主题、理由和地区；采购、处罚、预算、人事等 LOW 默认不选。
- 发现阶段的 `has_real_image` 固定为 false，不能在尚未抓取图片时伪称有真实图。
- 权威来源由 7 条扩展为 13 条；新增来源默认停用、禁止自动 AI、要求人工审核。

自动测试覆盖 202 job、进度恢复、终态、HIGH/LOW 筛选和幂等边界。国家卫健委栏目在当前网络返回 412，记录为外部站点反自动化限制，不伪造成功。
