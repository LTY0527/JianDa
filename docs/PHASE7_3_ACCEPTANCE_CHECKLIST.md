## 核心业务闭环

- [x] 平台管理员、机构管理员和审核员可使用对应演示账号登录。
- [x] 机构管理员可上传 PDF、PNG、JPG，文件类型与大小错误有自然中文提示。
- [x] AI 处理能生成字段、通俗版、步骤卡片、风险提示和原文引用。
- [x] AI 服务不可用时任务明确失败，不影响既有已发布内容。
- [x] 原文对照审核可定位页码、段落和引用片段。
- [x] 未确认字段不能进入审核；未审核内容不能发布。
- [x] 未保存内容离开时出现确认，取消后仍停留原页面。
- [x] 审核、发布和撤回均有明确反馈。
- [x] 发布后用户端详情、首页、资讯或办事入口可查看内容。
- [x] 撤回后首页、资讯、办事、收藏和助手均不再展示该内容。

## 用户端

### 首页与一级导航

- [x] 首页首屏能立即看到重要内容，深色头部不过高。
- [x] 首页、资讯、简达助手、办事、我的五项导航清晰可用。
- [x] 中央助手按钮突出但不夸张，不遮挡主要内容。
- [x] 首页无重复标题、随机长数字、英文占位词和明显测试数据。
- [x] 重要提醒、今日必看、办事快报和权威资讯层级清楚。

### 资讯与办事

- [x] 资讯频道、最新/重要/收藏筛选、搜索和加载更多可用。
- [x] 资讯卡片展示可信来源、自然日期、摘要、已读和收藏状态。
- [x] 办事可按对象、类型、机构筛选，并显示材料、时间、地点和步骤。
- [x] “问问这个事项”携带当前材料上下文进入简达助手。
- [x] “查看原文”进入正确原文，直接刷新仍可读取。

### 简达助手

- [x] 推荐问题自然，输入框、发送、语音能力提示、清空和历史会话易用。
- [x] 回答简明，引用包含来源、日期、原文片段和详情链接。
- [x] 没有可靠依据时明确说明，不补充医疗、金融或政策事实。
- [x] 已撤回内容不再被引用。
- [x] 助手历史仅保存在本机的说明清楚。

### 本机数据与设置

- [x] 收藏、浏览历史、已读状态可持久化，刷新后仍存在。
- [x] 我的页面可进入收藏、历史、阅读设置和内容偏好。
- [x] 游客状态与“仅保存在本机”说明明确。
- [x] 清除本机记录前有确认，取消不会清除数据。
- [x] 18/20/22/24px 字号刷新后保持，放大后不溢出。
- [x] 语速、高对比度、自动朗读、频道偏好和最近浏览开关可持久化。

- [x] 403、加载、空数据和失败状态完整。

## 导航与直接访问

- [x] 一级页面不显示返回按钮。
