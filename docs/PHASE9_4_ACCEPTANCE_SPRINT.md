# Phase 9.4 验收冲刺记录

## 本轮范围

本轮在 `feat/phase9-4-acceptance-sprint-v1` 增量完成异步处理、PDF 阅读诊断、材料类型与
长文处理、官网/微信公众号来源确认、同页手动扫描、历史封面补齐、H5 分类素材和环境同步。
不自动审核、不自动发布，不绕过 robots、登录、验证码、付费墙、防盗链或来源确认。

## 用户操作闭环

1. 平台管理员进入“权威来源管理”。
2. 在“扫描与导入”选择来源并点击“扫描最近文章”，设置时间、篇数和关键词。
3. 勾选未重复文章，点击“批量保存所选并加入 AI 队列”。
4. 在“AI 等待队列”人工批准；处理页自动轮询直到完成。
5. 在审核页核对正文、字段、页码、segment、图片来源和许可说明。
6. 允许缓存且策略已审核的网页图片会保存到本地；否则选择分类默认图。
7. 人工审核、人工发布，在用户端首页和详情页复核封面、原文和适老内容。

未知官网或公众号文章可先粘贴 URL，执行安全预览，再由平台管理员确认官方身份并继续导入。
公众号直接 URL 导入不等于能够自动发现该账号全部文章；没有稳定公开入口时只保留直接或
批量粘贴 URL。

## 历史封面补齐

入口：权威来源管理 → 高级自动采集设置 → 历史封面补齐。

- 必须先按来源、类型、状态和日期“预览补图范围”，再确认执行。
- 网页重新发现候选；候选能力与缓存许可分离。
- 已上传 PDF 第一页生成 `PDF_FIRST_PAGE` 本地 PNG。
- 已上传图片使用 `UPLOADED_ORIGINAL`。
- 来源未允许缓存时不下载第三方图片，公开端使用分类默认图。
- 来源允许缓存且图片策略已经人工审核时，批准候选才会安全下载到本地公开封面接口。
- 历史真实数据数量必须以 Docker 实际预览/执行结果为准，本文件不预填虚构数量。

## image_reviewed 规则

可自动确认：本地分类素材、平台自有素材、已上传原图、PDF 第一页，以及来源身份和图片使用
依据均已由平台管理员审核且允许缓存的候选。

必须人工确认：来源身份不确定、图片来自不同站点、许可说明缺失、来源图片策略未审核，以及
尚未确认官方账号身份的公众号图片。第三方图片确认前不公开。

## 环境同步

```powershell
.\scripts\sync-env.ps1
```

脚本从 `.env.example` 读取键，只向本机 `.env` 添加缺失键，不覆盖已有值。API Key、Secret、
Password、Token 类型字段仅补空键；控制台只显示新增键名。当前新增非敏感开关：

- `WEB_IMAGE_CANDIDATES_ENABLED=true`
- `HISTORICAL_COVER_BACKFILL_ENABLED=true`

全局 `CRAWL_AUTO_AI_ENABLED=true` 只表示具备自动 AI 能力；来源仍须单独启用，且受文章和
Token 预算保护。自动审核和自动发布始终关闭。
