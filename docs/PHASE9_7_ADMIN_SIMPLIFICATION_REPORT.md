# Phase 9.7 管理员减法报告

## 量化结果

| 项目 | 收口前 | 收口后 |
| --- | ---: | ---: |
| 来源卡默认可见操作 | 8 类 | 3 个（立即检查、查看新内容、更多） |
| 一级导航 | 5 | 5（未新增） |
| 普通检查新文章 | 需识别 discover/shadow/collect | 2 步：立即检查 → 查看新内容 |
| HelpTip 共享实现 | 0 | 1 个组件 + 1 份集中词典 |

## 隐藏与人话化

- 扫描范围、RSS/Sitemap、AI 等待队列、采集任务、预算、重试、去重和历史补图收入“高级管理”。
- discover/shadow/collect 在日常界面中分别表述为“检查新文章 / 预览抓取结果 / 加入内容中心”。
- 来源卡默认只显示健康、上次检查、新发现、下次检查和自动更新状态。
- HelpTip 通过 hover/click/focus/Enter/Space 打开，Esc 或点击外部关闭，并有 `aria` 语义和视口定位保护。

审核和发布业务步数本轮未修改，避免为追求数字减少而绕过人工审核。
