# 简达项目简报

## 产品定位

简达是面向社区、医院和政务服务机构的公共服务信息适老化平台。机构将 PDF、图片或公开资讯导入后，系统提取原文，生成结构化字段、通俗版和步骤卡片，经人工审核发布到移动端，供中老年用户大字或语音阅读。

## 核心用户

- 机构管理员：上传材料、查看处理状态、管理机构内容。
- 审核员：对照原文校验关键字段，审核、发布与撤回。
- 平台管理员：跨机构管理、导入权威公开信息。
- 普通读者：搜索、阅读、收藏并使用字号和语音功能。

## 演示闭环

登录 → 上传材料 → Mock AI 稳定处理 → 原文追溯与人工修改 → 审核发布 → H5 查看 → 调整字号/语音/收藏。

## 非目标

本课程版本不执行真实网络爬虫，不依赖真实模型 Key，不实现商业支付；Collector、外部 LLM 与 OCR 均保留适配器边界。
