## 已修复的真实可靠性问题

1. 质量模型现在保存综合 score、是否尝试 OCR、OCR 错误和人工复核标志。
2. `UNCERTAIN + OCR unavailable` 保留文字层并明确标记复核，不再静默当作完全正常。
3. OCR 后仍为 POOR 的文本不再被选中；最终 POOR 页不进入成功正文。
4. PNG/JPG/JPEG 继续走统一 fitz + OCR 路由，并补 JPEG 回归。
5. 72 页真实扫描件证明“大图+极薄隐藏文字”会进入逐页 OCR；没有把 125 字符薄文字层误判为全文。

## 真实缺口

- 文本+扫描混合 PDF：现有真实文件不能确证，自动生成的 `_generated-mixed.pdf` 明确排除。
- JPG：官方页面已发现两张原始通知 JPG，但 `xxgk.shbsq.gov.cn` 图片端点实测返回 502；`www.shbsq.gov.cn` 对应路径返回 404。未绕过或伪造。
- PNG：本机仅有产品设计图和页面截图，不属于原始通知；不用于凑数。
- 复杂布局：GB/T 45872 具备异常分页/布局特征，但仍需人工打开确认具体表格结构，因此保持 PARTIAL。
